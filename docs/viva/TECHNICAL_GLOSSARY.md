# 📖 LPU SmartNotice — Technical Glossary & Concept Dictionary
*Alphabetical reference of every technical term used in the project.*

---

### A
* **ACID Transactions:** (Atomicity, Consistency, Isolation, Durability). The guarantee that database operations in SQLite either complete fully or roll back completely, preventing corrupted states during announcement synchronization.
* **API (Application Programming Interface):** A set of rules and protocols allowing the frontend JavaScript interface to request data from and send data to the FastAPI Python backend.
* **Attachment Awareness:** The architectural capability in SmartNotice to distinguish between a notice having an attachment mentioned in text versus having the actual binary file contents available to read.

---

### B
* **Batch Embedding:** Sending multiple text documents (e.g. 20 notices) in a single HTTP API call to Google Gemini (`batchEmbedContents`) instead of 20 sequential network round-trips, speeding up ingestion by ~90%.
* **BM25 / Lexical Scoring:** An information retrieval algorithm that scores document relevance based on the frequency of matching query terms in the text, adjusted for document length.

---

### C
* **ChromaDB:** An open-source, embedded vector database used by SmartNotice to store and index 768-dimensional document vectors on disk (`storage/chroma_db/`) using HNSW (Hierarchical Navigable Small World) indexing.
* **Chunking:** The process of splitting long text documents into smaller, coherent passages before generating vector embeddings. In SmartNotice, individual announcements are compact enough to be embedded as whole documents with structured prefixes.
* **Content Hash:** A unique 64-character SHA-256 fingerprint generated from `SHA-256(title + full_content)`. Used for instant deduplication so identical notices are never duplicated in SQLite.
* **CORS (Cross-Origin Resource Sharing):** A browser security mechanism. Configured in `app/main.py` with `allow_private_network=True` so the 1-Click Browser Sync script running on `https://ums.lpu.in` can send notices to `http://localhost:8000`.
* **Cosine Similarity:** A mathematical metric calculating the cosine of the angle between two multi-dimensional vectors. Ranges from $0.0$ (orthogonal/unrelated) to $1.0$ (identical semantic direction).

---

### D
* **Decision Completeness:** A metadata field (`COMPLETE`, `PARTIAL`, `ATTACHMENT_MISSING`) indicating whether a notice has sufficient textual evidence to allow a student to make a decision without needing external unprovided files.
* **Deduplication:** The process in `UMSSyncService` of checking whether an incoming announcement already exists in SQLite using primary keys and content hashes.

---

### E
* **Embedding:** A dense numerical vector (array of floating-point numbers) representing the semantic meaning of a word, sentence, or document. SmartNotice uses 768-dimensional embeddings generated by `gemini-embedding-2`.
* **Endpoint:** A specific URL path and HTTP method exposed by the FastAPI backend (e.g. `POST /api/v1/chat`) to perform a specific function.

---

### F
* **FastAPI:** A high-performance, modern Python web framework based on Starlette and Pydantic used to build the SmartNotice REST API.
* **Few-Shot Prompting:** Providing an LLM with several concrete input-output examples inside the prompt to guide its reasoning and output format.

---

### G
* **Groundedness (Faithfulness):** The property of an AI response being strictly derived from and supported by retrieved evidence documents, with zero fabricated or unsupported facts.

---

### H
* **Hallucination:** When a Large Language Model invents false facts, non-existent dates, fictional room numbers, or bogus policies that sound confident and realistic. SmartNotice prevents this using strict RAG system prompt constraints.
* **HNSW (Hierarchical Navigable Small World):** The graph-based indexing algorithm used inside ChromaDB for ultra-fast approximate nearest neighbor vector search.
* **Hybrid Search:** Combining semantic vector search (which captures conceptual meaning) with lexical term search (which captures exact codes, room numbers, and names) to achieve optimal retrieval accuracy.

---

### I
* **Information Overload:** The cognitive difficulty students face when presented with thousands of unfiltered, chronological university announcements, causing critical notices to be overlooked.
* **Ingestion Pipeline:** The automated workflow that fetches, normalizes, deduplicates, structures, and indexes announcements into SQLite and ChromaDB.

---

### J
* **JSON (JavaScript Object Notation):** The lightweight, human-readable data format used for API communication and the baseline historical dataset (`all_announcements_with_attachment_flag.json`).

---

### L
* **Large Language Model (LLM):** A deep neural network trained on vast amounts of text that can understand, summarize, and generate human-like language. SmartNotice uses Google's `gemini-flash-lite-latest`.
* **Lexical Search:** Search based purely on exact word matching and term frequency rather than semantic meaning.

---

### M
* **Metadata:** Structured attributes attached to an announcement (such as category, target year, deadline date, urgency, and affected rooms) that enable filtering and scoring.
* **Multi-Model Failover:** A resilience pattern in `ChatService` where if the primary Gemini model hits a 503 high-demand spike or timeout, the request automatically falls back to alternative models (`gemini-3.5-flash`, `gemini-3.5-flash-lite`).

---

### N
* **NDCG (Normalized Discounted Cumulative Gain):** A metric used to evaluate ranking algorithms, measuring whether highly relevant documents appear near the top of the search results list.

---

### O
* **Offline Pseudo-Embedding:** A deterministic hashing algorithm implemented in `EmbeddingService` that generates 768-dimensional float vectors when the Gemini embedding API is unreachable or has exceeded its free-tier quota (1,000 requests/day).

---

### P
* **Personalization Engine:** The module in `app/services/personalization_service.py` that calculates an individual student's relevance score for each notice using a weighted mathematical formula.
* **Precision@K:** The fraction of the top $K$ retrieved documents that are truly relevant to the user's query.
* **Prompt Engineering:** The craft of designing structured, constraint-enforcing instructions given to an LLM to produce accurate, safe, and cited answers.
* **Pydantic:** A Python data validation library used by FastAPI and SmartNotice to enforce strict data types, models, and JSON schemas.

---

### R
* **RAG (Retrieval-Augmented Generation):** An AI architecture where an external search system retrieves relevant reference documents first, and passes them along with the user's question into an LLM to generate an accurate, grounded answer with citations.
* **Recall@K:** The fraction of all relevant documents in the entire corpus that are successfully retrieved in the top $K$ results.
* **Reciprocal Rank Fusion (RRF):** A rank aggregation algorithm that merges ordered results from multiple search systems (vector + lexical) into a single, unified ranking.
* **REST (Representational State Transfer):** The architectural style of web services using standard HTTP verbs (`GET`, `POST`, `DELETE`) and stateless communication.

---

### S
* **Semantic Search:** Searching by meaning, concept, and intent rather than exact literal keyword matching. Example: searching for *"fee due"* retrieves a notice titled *"TUITION PAYMENT TIMELINE"*.
* **SQLite:** A lightweight, self-contained, serverless relational database engine stored in a single file on disk (`storage/smartnotice.db`).
* **Stopwords:** Common words (e.g. *"the"*, *"is"*, *"in"*, *"announcements"*) removed during text indexing so they do not artificially distort relevance scores.

---

### T
* **Temporal Disambiguation:** The logic in `app/services/temporal_service.py` that resolves relative words like *"today"*, *"tomorrow"*, or *"yesterday"* against a reference calendar date to prevent claiming a notice from 2024 applies to today.
* **Timetable Impact:** The analysis of comparing a student's enrolled courses and assigned rooms against university room-exemption notices to alert students of relocated or cancelled classes.

---

### U
* **Uvicorn:** A lightning-fast ASGI (Asynchronous Server Gateway Interface) web server implementation for Python used to serve the FastAPI application.

---

### V
* **Vector Database:** A specialized database optimized for storing, indexing, and querying multi-dimensional vector embeddings using geometric distance metrics (like Cosine or Euclidean distance).
